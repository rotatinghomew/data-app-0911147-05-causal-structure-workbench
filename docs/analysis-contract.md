# 分析资料与解释边界

## 探索资料
observations 的 cohort 与 learner 为分组键。variables 提供测量时点、离散或连续类型；knowledge 有 forbidden、required 和 temporal_order。现有 correlation 只返回成对有效记录的描述性相关，不构成条件独立证据。
## 结构语义
候选输出需要表达无法唯一确定的方向及依赖的无混杂、忠实性等假设。选择何种发现方法与如何支持混合变量由开发者论证，不要求覆盖无法可靠处理的输入；不支持时要明确说明。知识冲突和有向环应在发布前报告。不能把相关性正负号当作边方向。
## 可检验结构
analysis_cases 有线性高斯链、叉形、碰撞点及包含潜在共同原因的资料。链与叉形的观测等价不能被包装为数据已唯一识别；碰撞点需要相应的分离证据。独立数据或退化常数应给出可解释结果。统计检验的人群、校正和稳定性依据随图可查。
