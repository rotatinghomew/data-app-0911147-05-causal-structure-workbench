# 分析资料与解释边界

## 探索资料
observations 的 cohort 与 learner 为分组键。variables 提供测量时点、离散或连续类型；knowledge 有 forbidden、required 和 temporal_order。现有 correlation 只返回成对有效记录的描述性相关，不构成条件独立证据。

## 结构候选探索（/api/discovery）
分析员在页面提交观测集合（人群与变量）、检验参数与知识（时间先后、必需方向、禁止方向），服务在同一观测集合上执行约束发现：

- 观测集合：所选人群内、所选变量整行完整的记录。一次运行中的全部条件独立检验共用该矩阵，运行结果带观测集合指纹；更换人群或变量即构成新的观测集合，不把不同集合的统计量拼进同一张图。
- 检验：Fisher z 偏相关（线性、近似高斯假设），逐检验使用同一显著性水平，未做多重比较校正；全部检验记录（条件集、n、r、p、判定）随图可查。常数列与自由度不足给出可解释说明，不以 NaN 冒充数值。
- 骨架：PC-stable 删边并记录分离集；被分离的关系连同删边证据一并展示。
- 定向：v 结构（分离集证据）+ Meek 规则 + 提交知识。required 为硬方向，temporal_order 与 forbidden 只排除方向。方向未定的边明确标出，并给出定向所需的额外假设；知识冲突（有向环、与数据定向冲突、required 边不相邻）在发布前报告，不被静默应用。
- 候选：枚举等价类中与知识相容的 DAG（不新增碰撞点、无有向环），供比较；过多时只展示等价类并说明。
- 稳定程度：自助重抽样重复同一流程，报告邻接频率与各方向频率；同一请求复现同一结果。

## 结构语义
候选输出表达无法唯一确定的方向及依赖的无混杂、忠实性等假设。链与叉形的观测等价不被包装为数据已唯一识别；碰撞点需要相应的分离证据。独立数据或退化常数给出可解释结果。统计检验的人群、校正和稳定性依据随图可查。不能把相关性正负号当作边方向。

## 用途边界
保存的图快照带观测集合指纹与「供后续实验设计讨论，不构成学生个人决策依据」的用途说明；探索台不宣布任何变量必然导致另一变量。
